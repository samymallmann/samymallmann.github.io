Assembler para MIPS

Montador de duas passadas para o subconjunto de MIPS decodificado pelo processador do projeto de pipeline: resolve rótulos e codifica cada instrução em binário de 32 bits, pronto pro $readmemb. Reconhece um padrão fixo de exatamente 12 instruções — nem uma a mais — espelhando de propósito o que o processador realmente decodifica. O .bin gerado é carregado direto no projeto Quartus Prime e roda no processador embarcado numa FPGA DE10-Lite.

Python MIPS FPGA Quartus Prime
